# Reusable agent prompts

These are manually invoked prompt templates, not always-on instructions or
skills. Apply one explicitly when needed; each prompt supplements the current
request, preserves its scope, and adds concise feedback.

Use `planning-guidelines.prompt.md` as the main prompt for issue planning. The
other prompts are focused checks that can supplement it.

Keep prompts as `*.prompt.md`. Do not add `AGENTS.md` or `SKILL.md` here.
