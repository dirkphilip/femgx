# Documentation instructions

- The `docs/` API reference describes the current public API only.
- Do not add migration maps, old-to-new compatibility tables, or historical
  API mapping pages here. Update the current guides and their source links
  instead.
- In TypeDoc-rendered Markdown, link public symbols with qualified `{@link}`
  tags such as `{@link root.Scene Scene}`; do not link API symbols to GitHub
  source files.
